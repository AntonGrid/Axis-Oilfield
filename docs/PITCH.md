# Пилот «Axis-Oilfield» — цифровой контроль склада МТР

> **Презентация для руководства.** Слайд-дек: `docs/presentation/index.html`
> (открывается в браузере). Назначение — показать ценность, не технологию.

---

## 1. Ситуация: с чем сталкивается склад МТР сегодня

| Боль | Последствие |
|---|---|
| **Пересортица** — фактический товар расходится с учётом | выявляется только при инвентаризации, когда потери уже произошли |
| **Распределённые кусты** — десятки площадок за сотни километров | никто не знает, что где лежит; поиск «наугад» |
| **Нет независимого аудит-следа** | споры по списаниям, «потеряшки» без доказательств |
| **Оффлайн-площадки** | бумага остаётся единственным учётом |
| **1С — учёт «по документам»** | физика не подтверждается в момент события |

## 2. Чем это обходится компании

- брак при монтаже из-за «не той трубы/реагента» → ремонт, простой скважин;
- **дублирующие закупки** того, что уже где-то лежит;
- недели инвентаризации и расхождения по итогам;
- споры и нецелевое использование МТР без доказательств.

## 3. Предложение: подписанная прослеживаемость каждой единицы

```
QR-метка на единице МТР  +  сканирование на каждом шаге  =  подписанное событие
```

- **Приёмка** — сканирование сверяет факт с ТТН/сертификатом (пересортица на входе блокируется);
- **Хранение** — каждая единица привязана к адресу: куст → контейнер → стеллаж → ячейка;
- **Перемещение на куст** — подписанная цепочка custody;
- **Выдача по наряду** — сверка артикула с нарядом, FEFO, сертификаты;
- **Инвентаризация** — сканирование факта → мгновенный отчёт «что расходится».

## 4. Что это даёт

- **пересортица блокируется в момент сканирования**, а не находится через квартал;
- **карта «что где лежит»** по всем кустам — поиск за 10 секунд;
- **аудит-след без споров**: кто, что, когда — подписано и неизменяемо;
- **инвентаризация в разы быстрее** (скан вместо пересчёта);
- **оффлайн-режим**: события подписываются на кусте без интернета и синхронизируются позже;
- меньше потерь, меньше дублирующих закупок.

## 5. Пилот: дёшево, быстро, без замены 1С

| Параметр | Значение |
|---|---|
| Позиции | 1–3 «болевые» (например, НКТ, реагенты) |
| Оборудование | телефон кладовщика + QR-стикеры |
| Срок | 2 недели до первого отчёта руководству |
| Интеграция | **не заменяет 1С** — параллельный контур физического подтверждения; мост к 1С — 2-й этап |
| Итог | отчёт: пересортица/расхождения по позициям, карта кустов |

## 6. Технология (коротко, для ИТ-блока)

- Открытый стандарт **Axis Protocol** (Apache 2.0), подписи **Ed25519**;
- Логика домена — чистый Python (`src/oilfield`, 15 тестов), доверие — Axis Core;
- Схема: `скан → подпись → событие → политика → аномалия/отчёт`;
- Работающий демо: `python examples/oilfield_inventory.py`.

## 7. Следующие шаги

1. Выбрать пилотные позиции и замерить текущие потери (база).
2. Наклеить QR-метки, выдать кладовщику телефон со сканером.
3. Через 2 недели — отчёт: пересортица, расхождения, «карта кустов».
4. Решение о масштабировании на все склады/кусты.
