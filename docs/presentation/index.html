Ситуация

С какими болями живёт склад сегодня

Пересортица

Факт расходится с учётом. Находится при инвентаризации — когда потери уже произошли.

Кусты далеко

Десятки площадок за сотни километров. Никто не знает, что где лежит — поиск «наугад».

Нет аудит-следа

Споры по списаниям и «потеряшкам» без независимых доказательств.

Оффлайн-площадки

На кустах нестабильный интернет — бумага остаётся единственным учётом.

Цена проблемы

Чем это обходится компании

Брак на монтаже

«Не та труба / не тот реагент» на кусте → ремонт, простой скважин.

Дублирующие закупки

Покупаем то, что уже где-то лежит — потому что не видим карту.

Недели инвентаризации

Ручной пересчёт вместо сканирования; расхождения по итогам.

Споры и потери

Нецелевое использование МТР и «потеряшки» без доказательств.

Пилот

Дёшево, быстро, без замены 1С

Что берём

  • 1–3 «болевые» позиции (например, НКТ, реагенты)
  • телефон кладовщика + QR-стикеры
  • 2 недели до первого отчёта руководству

Что получаем

  • отчёт: пересортица/расхождения по позициям
  • карта «что где лежит» по кустам
  • аудит-след всех движений
Важно: не заменяет 1С — работает как параллельный контур физического подтверждения; мост к 1С — второй этап.
Для ИТ-блока

Технология — коротко

Открытый стандарт

Axis Protocol, Apache 2.0 — доменно-агностичный слой доверия. Подписи Ed25519, события неизменяемы.

Схема

скан → подпись → событие → политика → аномалия/отчёт. Логика домена — чистый Python, 15 автотестов.

Безопасность

ключ подписи на устройстве кладовщика; сервер только проверяет. Оффлайн-подпись на кустах.

Интеграция

1С остаётся системой учёта; Axis добавляет физическое подтверждение. Мост (OData/выгрузка) — этап 2.
